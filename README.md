# ความจำสรุปเรื่อง (Memory TH)

ส่วนขยาย SillyTavern สำหรับสรุปแชทเป็น "ก้อนความจำ" แล้วส่งเฉพาะสรุปแทนข้อความเก่า เพื่อประหยัดโทเคน

## วิธีติดตั้ง
1. แตกไฟล์ให้ได้โฟลเดอร์ `memory-th`
2. วางไว้ที่ `SillyTavern/public/scripts/extensions/third-party/memory-th`
   (หรือ `data/<ชื่อผู้ใช้>/extensions/memory-th`)
3. รีสตาร์ต SillyTavern แล้วรีเฟรชหน้าเว็บ
4. เปิด Extensions (ไอคอนลูกบาศก์) จะเห็นเมนู "🧠 ความจำสรุปเรื่อง"

## ฟีเจอร์
- แสดงสถานะ: จำนวนก้อนความจำ, สรุปถึงข้อความที่เท่าไร, ยังไม่สรุปกี่ข้อความ, โทเคนที่ส่งล่าสุด
- สรุปอัตโนมัติทุก N ข้อความ หรือกดสรุปเอง
- สรุปช่วงที่เลือก (ระบุเลขข้อความ)
- คลังความจำ: แก้ไข ลบ ก้อนความจำและเรื่องย่อรวม
- ดูสิ่งที่ส่งล่าสุด
- เริ่มแชทใหม่ต่อเรื่อง (ย้ายความจำไปแชทใหม่)
- ไม่ส่งข้อความที่สรุปแล้ว (ซ่อนข้อความที่สรุปแล้วจาก prompt)
- เมื่อก้อนความจำเกินกำหนด จะรวมก้อนเก่าเป็น "เรื่องย่อรวม" อัตโนมัติ

## หมายเหตุ
- ใช้ API หลักที่เชื่อมต่ออยู่ในการสรุป (ผ่าน generateRaw) การสรุปจึงใช้โทเคนตามปกติ
- ข้อความที่สรุปแล้วจะถูกซ่อน (is_system) เพื่อไม่ให้ถูกส่ง สามารถเลิกซ่อนได้จากไอคอนตาของข้อความนั้น
- ทดสอบโดยอิงโครงสร้าง API ของ SillyTavern รุ่นใหม่ ถ้าฟังก์ชันไหนไม่ทำงานในรุ่นของคุณ ดู error ใน Console (F12)
